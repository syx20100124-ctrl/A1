================================================================
第一章  万用表
================================================================

万用表是电子工程师最基本、最常用的测量工具，
可测量直流/交流电压、直流/交流电流、电阻，
以及二极管、三极管、电容、频率等（视型号而定）。

--------------------------------------------------------------
1.1  指针式万用表
--------------------------------------------------------------

【结构与组成】

表头（电流计）：
  核心部件，利用安培计原理偏转指针
  满偏电流通常50μA~200μA
  内阻越低，影响被测电路越小

转换开关（量程选择）：
  旋钮式，选择测量功能和量程
  错误选择量程可能损坏表头

表笔孔（端子）：
  "+"（正/红表笔）：公共正极
  "-"（负/黑表笔）：公共负极（注意：内部电池负极接"+"端）
  特别注意：测量电阻时，红表笔为内部电池负极！
  部分万用表有单独的电流测量孔（如10A）

刻度盘：
  多条弧线刻度，不同功能读不同线
  欧姆（Ω）刻度：从右到左，刻度不均匀（右侧为0）
  电压/电流（DC V/A）：均匀刻度，一般从左到右
  AC 刻度：与DC略有不同
  hFE：晶体管放大倍数刻度
  LI：负载电流刻度

调零旋钮：
  机械调零：调整指针在无输入时指向0（左端）
  欧姆调零：测量电阻前，短接两表笔，调节使指针指向0Ω（右端）

【型号举例】
MF47型：国内经典，量程丰富，价格低廉，教学常用
MF500型：更高精度版本
Simpson 260：欧美经典，坚固耐用
Triplett 630：经典美系

【量程选择原则】
原则：选择量程时，使指针偏转在满偏的1/3~2/3区域（弧长段）
读数最准确的区域：量程的1/3~2/3处

直流电压（DCV）：
  量程通常：0.1V / 0.5V / 2.5V / 10V / 50V / 250V / 500V / 1000V
  选择：略大于估计被测电压的量程
  未知电压：先选最大量程，再逐步减小

交流电压（ACV）：
  量程类似DCV
  指针式万用表的ACV精度低于DCV（整流误差）
  只适合测50Hz工频，高频交流误差大

直流电流（DCmA）：
  量程：50μA / 500μA / 5mA / 50mA / 500mA / 5A
  测量时必须串联在被测回路中（断开电路后串入）
  绝对不能并联在电源两端测电流！

交流电流（ACmA）：
  类似DCmA，通常量程较少

电阻（Ω）：
  量程：R×1 / R×10 / R×100 / R×1k / R×10k
  读数 = 指针数字 × 量程倍率
  换挡后必须重新调零（每换挡欧姆调零一次）

【指针式万用表操作步骤】

测直流电压（以测12V蓄电池为例）：
1. 红表笔插"+"端，黑表笔插"-"端
2. 转换开关置DCV 50V（估计12V，选略大的50V）
3. 检查机械零点（无输入时指针是否在最左端0位置，不在则调节机械调零旋钮）
4. 红表笔接正极，黑表笔接负极（直流必须注意极性！）
5. 读取指针位置，对应直流电压刻度线
6. 实际电压 = 指针读数
7. 若指针偏转过小（<1/3满偏），降一挡量程重测

测电阻（以测1kΩ电阻为例）：
1. 选择量程R×100
2. 两表笔短接，调欧姆调零旋钮使指针指向0Ω（最右端）
3. 分开表笔，将表笔接电阻两端（不在路，即电阻从电路中取下）
4. 读指针在欧姆刻度上的数值（从右向左读，最右为0，最左为∞）
5. 实际电阻 = 指针读数 × 量程倍率（100）= 10 × 100 = 1kΩ
6. 若指针偏在中间位置（1/3~2/3满偏），读数最准确
   偏左（>10倍量程）→升挡；偏右（<1/10满偏）→降挡

注意：在路测电阻时，必须先断开电源，否则读数错误甚至损坏表头

测二极管（判断好坏和极性）：
红表笔接内部电池负极！黑表笔接正极！（与标注相反！）
1. 选R×100
2. 短接调零
3. 一种接法读数：正向导通，阻值应在几十Ω~数千Ω（硅管更大）
4. 反向接法：应接近∞（不偏或微偏）
5. 两次都很小→击穿短路；两次都∞→断路

测晶体管hFE（放大倍数）：
部分万用表有hFE插孔（B/C/E三孔，分NPN/PNP区域）
1. 识别晶体管型号，确认NPN或PNP
2. 根据标示插入B（基极）、C（集电极）、E（发射极）孔
3. 选择hFE量程
4. 读指针对应hFE刻度线数值

【指针表优缺点】
优点：
  直观显示变化趋势（指针连续摆动）
  适合观察缓变信号（如旋钮调节时的连续变化）
  无需电池（测电压/电流时）
  价格低，结构简单，适合入门学习

缺点：
  读数误差大（视角误差），精度低（约2.5级）
  测量项目受限
  欧姆刻度非线性，中段读数较好
  需要学会读多条刻度线

--------------------------------------------------------------
1.2  数字万用表（手持）
--------------------------------------------------------------

【原理】
使用双积分ADC将模拟量转为数字显示
精度高，读数直接，不需视角补偿

【型号推荐】
入门：DT830B/DT9205A（国产，百元以下）
主流：UNI-T UT61E+（自动量程，精度高）
     Fluke 17B+/115/117（福禄克，专业级）
     Victor VC9808+（万用资源测量）
专业：Fluke 175/177/179，Agilent（是德科技）34401A

【显示位数含义】
3½位：最大显示1999（如DT830B）
4½位：最大显示19999（更高精度）
6½位：台式仪器级别

【面板说明】

LCD显示：
  主显示：数字读数
  辅助显示：某些型号有第二行
  负号（-）：直流测量极性反了
  OL 或 1 ：超量程（Over Limit），选更大量程
  HOLD：数据保持
  MIN/MAX：最小/最大记录
  AUTO：自动量程

量程旋钮：
  DCV（直流电压）：200mV / 2V / 20V / 200V / 1000V
  ACV（交流电压）：2V / 20V / 200V / 750V
  DCmA/DCA（直流电流）：需插电流孔（200μA / 2mA / 20mA / 200mA / 10A）
  ACA（交流电流）：类似
  Ω（电阻）：200Ω / 2kΩ / 20kΩ / 200kΩ / 2MΩ / 20MΩ
  二极管测试（→|—）：
  通断蜂鸣（)))）：
  电容（F）：（部分型号）
  频率（Hz）：（部分型号）
  hFE：晶体管放大倍数（部分型号）

表笔插孔：
  COM（黑表笔）：公共/负极
  VΩHz（红表笔）：电压/电阻/频率/二极管测量
  mA（红表笔）：小电流（200mA以下）
  10A（红表笔）：大电流（10A），保险丝额定更大

【详细操作步骤】

--- 测直流电压（如测充电宝输出5V）---
1. 黑表笔插COM，红表笔插VΩHz
2. 旋钮转至DCV 20V（5V在20V量程内）
3. 红表笔接正极（+），黑表笔接负极（-）
4. 读显示值（如4.98V）
5. 如果显示负值，说明极性接反（正常现象，读绝对值即可）
6. 如果显示OL，选更大量程（20V→200V→1000V）

--- 测交流电压（如测市电220V）---
警告：220V致命！确保绝缘良好！
1. 旋钮转至ACV 750V（220V在750V量程内）
2. 表笔直接插入插座（无极性，随意）
3. 读数（正常约195~235V）
注意：数字表ACV测量范围通常到45~400Hz，高频不准确

--- 测电阻（如测色环电阻）---
1. 旋钮转至Ω，选合适量程（估计值的1~10倍量程）
   自动量程表：转至Ω即可
2. 红表笔接一端，黑表笔接另一端（无极性）
3. 读数
4. 重要：在路测量时会受并联电路影响，应在路外测量
   （或断开被测电阻的一个焊点）
5. 用手指捏住表笔金属部分：人体并联会影响高阻测量（>10kΩ）

--- 测二极管 ---
1. 旋钮转至二极管测试（→|—）
2. 红表笔接正极（阳极），黑表笔接负极（阴极）
3. 显示正向压降（硅：0.55~0.70V，肖特基：0.15~0.40V，LED：1.8~3.5V）
4. 互换表笔：正常二极管显示OL（反向截止）
5. 两次都显示0~数百：击穿短路
6. 两次都OL：断路
注意：数字表红表笔为正极（与指针表相反）

--- 测通断（蜂鸣器功能）---
1. 旋钮转至蜂鸣（)))）
2. 表笔接触被测导线/触点
3. 蜂鸣（声音响）：低阻（通常<30Ω）视为通路
4. 无声：断路或阻值过高
用途：快速检查导线通断，PCB走线，开关状态

--- 测直流电流（如测LED工作电流）---
重要：电流表必须串联，这需要断开电路！
1. 断开被测电路（断开一条连线）
2. 黑表笔插COM，红表笔插mA孔（估计<200mA）
3. 旋钮转至DCmA 200mA
4. 将表笔串接入断开处（电流从红表笔进，COM出）
5. 接通电源，读数
6. 如果读数接近量程上限→断电→换10A孔重测
注意：严禁将电流档表笔直接接到电源两端！会短路烧毁保险丝！

--- 测电容（如测100μF电解电容）---
（需要有电容测量功能）
1. 电容放电！先短接电容两端（尤其是大容量电解电容）
2. 旋钮转至电容测量（F）
3. 部分仪表有专用插孔，部分用VΩ孔
4. 电解电容注意极性（红"+"，黑"-"）
5. 等待稳定读数（大电容需要数秒~数十秒）
6. 允许误差：普通电容±10~20%都正常

--- 测晶体管hFE ---
1. 找到晶体管插座（B/C/E三孔，通常在表盘边）
2. 识别晶体管极性（NPN或PNP，查手册或封装标记）
3. 对应NPN区或PNP区，插入B、C、E对应孔
4. 旋钮转至hFE
5. 读数（典型值：小功率管50~300，功率管20~100）

【安全使用注意事项】
1. 测量前确认量程正确，再接表笔
2. 高压（>60VDC、>30VAC）时特别小心
3. 测电流时必须串联，绝不能并联
4. 测电阻时被测元件必须断电（储能电容先放电）
5. 换量程时先撤表笔，再转旋钮
6. 注意表笔绝缘层完整性，破损立刻更换

【保险丝更换】
过流时保险丝熔断，万用表无法测量（测电流量程）
更换步骤：
1. 确认规格（印在万用表背面，如250mA/250V）
2. 拆开后盖，取出保险丝
3. 用相同规格替换（不能用导线替代，危险！）

--------------------------------------------------------------
1.3  台式数字万用表
--------------------------------------------------------------

【与手持表的区别】
位数更高（5½~8½位）
精度更高（0.003%~0.0002%）
稳定性更好（温度补偿）
功能更丰富（4线电阻，温度，电容，内置校准）
体积大，需要供电，用于实验室精密测量

【典型型号】
Keysight（安捷伦）34461A：6½位，14量程，USB/LAN接口
Fluke 8846A：6½位，高精度
Victor VC8145：国产，5½位，性价比高
UNI-T UT8803N+：国产中档台式

【面板功能说明（以6½位台式为例）】

前面板：
  大型LCD/VFD显示：主副两行显示
  功能键：DCV、ACV、DCI、ACI、Ω（2线）、Ω（4线）、CAP、FREQ、TEMP等
  量程键：AUTO（自动）、MANUAL（手动）
  触发键：TRIG（手动触发读数）
  读数速率：SLOW/MED/FAST（影响读数次数和精度）
  数学功能：NULL（置零）、MIN/MAX、统计、dB
  接口：前面板接线柱（Hi/Lo/HiSense/LoSense）

后面板：
  GP-IB/IEEE-488：经典仪器总线接口
  USB/LAN：现代通信接口
  外触发输入
  保险丝

【4线电阻测量（开尔文连接）原理】
2线测量包含表笔和导线的电阻误差（数Ω~数十mΩ）
4线消除此误差：用2根线提供测试电流，另2根线测量电压

操作：
1. 四根表笔分别连接：
   电流输出Hi → 被测电阻 → 电流输出Lo（提供电流）
   电压测量Hi → 被测电阻（靠近被测）→ 电压测量Lo
2. 选4线Ω功能
3. 表内自动计算：R = V测/I供
4. 用于精密测量：小电阻（<10Ω）必须用4线法

【NULL置零功能】
消除固定偏差，如表笔电阻、系统偏置
操作：先将表笔短接（或接到已知参考），按NULL置零，再测量

【dB测量】
将电压转换为分贝（参考600Ω负载或自定义参考）
用于音频、射频信号强度测量

【台式表连接计算机】
通过GPIB（需要GPIB卡）或USB
SCPI命令控制读数（如：MEAS:VOLT:DC? 10,0.001）
Python控制示例：
  import pyvisa
  rm = pyvisa.ResourceManager()
  inst = rm.open_resource('USB0::...')
  reading = inst.query('MEAS:VOLT:DC?')

第二章  示波器
================================================================

示波器是模拟/数字电路调试最重要的仪器，
可观察信号的波形、幅度、频率、相位和时序。

--------------------------------------------------------------
2.1  模拟示波器
--------------------------------------------------------------

【结构原理】
阴极射线管（CRT）：电子束打在荧光屏上发光
水平偏转板（X轴）：时基扫描，由内部锯齿波驱动
垂直偏转板（Y轴）：被测信号偏转

【典型型号】
泰克（Tektronix）485：350MHz，经典教学示波器
泰克2465：400MHz，经典
日立V-422：40MHz，常见实验室
国产：GOS-620、SC-16等

【面板主要控制旋钮】

VOLTS/DIV（垂直灵敏度）：
  每格（Division）对应的电压值
  范围：1mV/div~20V/div（典型）
  越小，放大倍数越大，可观察微弱信号

TIME/DIV（时基）：
  每格对应的时间
  范围：1ns/div~0.5s/div
  越小，时间分辨率越高，可观察高频信号

触发（TRIGGER）：
  Source：选择触发源（CH1/CH2/外部/线路）
  Level：触发电平（信号在此电平时开始扫描）
  Slope：上升沿（+）或下降沿（-）触发
  Mode：AUTO（有信号无信号都扫）/NORMAL（有触发才扫）/SINGLE

Y轴位置（POSITION）：
  上下移动波形

X轴位置（HORIZONTAL POSITION）：
  左右移动波形

AC/DC/GND耦合：
  DC：直接耦合，显示信号的直流分量+交流分量
  AC：隔直电容，只显示交流部分（消除直流偏置）
  GND：输入接地，找零基准线

【使用步骤】
1. 开机，等待预热（模拟示波器通常需要数分钟稳定）
2. 找到扫描基线：调FOCUS、INTENSITY使一条水平亮线出现
3. 使用探头校准端口（通常在面板侧面，1kHz方波）
   若方波顶部倾斜→过补偿/欠补偿→调节探头补偿电容至顶部平直
4. 将信号接入CH1，选择合适VOLTS/DIV和TIME/DIV
5. 调触发：先设Auto模式，调Level至波形稳定

--------------------------------------------------------------
2.2  数字存储示波器（DSO）
--------------------------------------------------------------

【特点与优势】
A/D采样→数字存储→液晶显示
可以存储波形，分析单次事件
自动测量功能（频率、幅度、周期、上升时间等）
支持FFT（频域分析）
可连接计算机保存数据

【主流品牌型号】
教学入门：
  Rigol DS1054Z（4通道，50MHz，可解锁100MHz，约1000~1500元）
  UNI-T UTD2102CEX（100MHz，双通道）

中档：
  Rigol DS2072A（70MHz，2通道，7寸屏）
  Siglent SDS1202X-E（200MHz，2通道，功能丰富）

专业：
  Tektronix TBS2104（100MHz，4通道，USB）
  Keysight DSOX1204G（70/100MHz，可升级）

高端：
  Tektronix MDO3000系列（混合域，内置频谱分析）
  Keysight InfiniiVision 6000系列

【面板功能详解】

垂直系统：
  VOLTS/DIV旋钮：同模拟示波器
  通道耦合（CH Menu > Coupling）：
    DC耦合：观察直流信号，看真实波形
    AC耦合：滤去直流，看小幅度交流叠加在大直流上的信号
    GND：输入接地，标定零电平位置
  BW Limit（带宽限制）：打开后限制带宽到20MHz，
    可减少高频噪声，观察低频信号更清晰
  Probe（探头倍率）：选1×或10×，必须与实际探头匹配

水平系统：
  TIME/DIV旋钮：同模拟示波器
  水平位置旋钮：移动波形
  采样率：决定能准确捕获的最高频率（奈奎斯特：采样率≥2倍信号频率）
  存储深度：影响波形记录的时间长度

触发系统：
  触发源（CH1/CH2/外部/市电）
  触发类型：
    Edge（边沿）：最常用，上升/下降/任意沿
    Pulse（脉冲宽度）：捕获特定宽度脉冲
    Slope（斜率）：特定上升/下降速率
    Video（视频）：解码视频信号
    Serial（串行）：解码UART/I2C/SPI（某些型号）
  触发模式：
    Auto（自动）：无触发时也显示，适合初始找信号
    Normal（正常）：只在满足触发条件时更新，适合稳定观察
    Single（单次）：捕获一次波形后停止，适合单次事件
  触发耦合：DC/AC/HF Reject/LF Reject

Acquire（采集）设置：
  Normal（正常采样）：标准模式
  Peak Detect（峰值检测）：捕获窄脉冲和毛刺
  Average（平均）：减少随机噪声（2/4/8/16/...次平均）
  High Resolution（高分辨率）：低采样率时提高有效位数

自动测量（Measure/Meas菜单）：
  Vpp：峰峰值电压
  Vmax/Vmin：最大/最小电压
  Vavg：平均电压（DC值）
  Vrms：有效值（AC+DC）
  Frequency：频率
  Period：周期
  Duty：占空比
  Rise Time：10%~90%上升时间
  Fall Time：下降时间
  Width（正脉冲宽度），NWidth（负脉冲宽度）
  Phase：两通道相位差

光标测量（Cursor）：
  Manual：手动放置两根游标线（X或Y）
  读两游标间的差值（ΔV 或 Δt），计算频率等
  更灵活，适合手动测量特定位置

FFT（频谱分析）：
  Math菜单→FFT
  将时域波形转为频域，显示各频率分量
  设置：
    窗函数：Hanning（通用），Blackman（频率精度），Rectangular（时间精度）
    中心频率和频率跨度
  用途：分析谐波，找干扰频率，EMI初步排查

【探头使用与校准】

探头类型：
  1×探头：信号不衰减，带宽低（约6~10MHz）
  10×探头：信号衰减10倍，带宽高（与示波器标称带宽匹配），最常用
  100×探头：用于高压测量
  无源差分探头：测量浮地信号（高压MOSFET栅极等）
  电流探头（钳形）：非接触测量电流

探头补偿（必须做！）：
1. 将探头勾子接到示波器的"CAL"端（1kHz方波输出）
2. 地线夹接到旁边的地
3. 将VOLTS/DIV和TIME/DIV调到合适范围（如1V/div，0.5ms/div）
4. 观察方波波形：
   顶部平直：补偿正确
   顶部向上隆起：过补偿，用塑料螺丝刀调探头端的微调电容减小
   顶部向下塌陷：欠补偿，调大
5. 每次换探头或示波器都要重新补偿

地线回路问题（重要！）：
探头地线接法不当会引入干扰，甚至损坏电路
原则：地线尽量短（短的地线弹簧比长的地线夹好）
高频电路：使用探头末端专用地线适配器（或焊接测试孔）

【数字示波器特有技巧】

触发释抑（Hold-off）：
  设定两次触发之间的最短间隔
  用于波形重复但不规则时稳定显示

波形存储：
  保存到USB（截图PNG，或原始CSV数据）
  CSV数据可用Python/Excel分析

Roll（滚动）模式：
  TIME/DIV>100ms时用，实时滚动显示
  适合观察缓慢变化信号（温度，电机转速）

XY模式：
  X轴=CH1，Y轴=CH2，显示李萨如图
  用于相位差测量，频率比较

参考波形：
  保存一条波形为参考（REF），与当前波形对比

【示波器带宽、采样率关系】
带宽：-3dB截止频率（正弦波幅度下降29%处的频率）
经验：信号频率 × 5 ≤ 示波器带宽（才能看到准确波形）
采样率：≥ 5倍以上信号最高频率，才不产生严重混叠
  Rigol DS1054Z默认50MHz带宽，采样率1GSa/s

3.1  函数信号发生器

【功能】

【面板参数】

幅度：峰峰值Vpp，通常10mVpp~20Vpp

  重要：输出设定50Ω负载时，实际幅度=设定值
        若接高阻负载（>1kΩ），实际幅度≈设定值×2

【常见型号】
Rigol DG1022Z：双通道，25MHz，任意波
Siglent SDG1032X：双通道，30MHz
Tektronix AFG1022：25MHz，双通道
Keysight 33500B系列：专业级，30MHz

【使用步骤（测试放大器频率响应）】
1. 打开信号源，选择正弦波
2. 设置频率为1kHz，幅度100mVpp
3. 调节偏置为0（纯交流输出）
4. 接到放大器输入（正确接地）
5. 示波器CH1监测输入，CH2监测输出
6. 改变频率，观察输出幅度变化→频率响应曲线

【注意事项】
输出端切勿短路（损坏内部保护电路）
高频信号使用高质量同轴电缆，不用杜邦线（杜邦线高频损耗大）

--------------------------------------------------------------
4.1  线性直流稳压电源
--------------------------------------------------------------

【特点】
使用线性调节（晶体管串联调节），纹波极小
发热较大，噪声低，稳定性好
适合模拟电路、射频电路的供电

【面板说明】

电压调节旋钮（VOLTAGE）：
  调节输出电压（粗调+细调两个旋钮）

电流调节旋钮（CURRENT）：
  设置电流限制，超过此值进入恒流模式

输出端子：
  +（红）、-（黑）、接地（绿/黄，机壳地）

工作模式指示：
  CV（Constant Voltage，恒压）：正常工作，输出恒定电压
  CC（Constant Current，恒流）：负载过重，进入恒流保护
  OVP（Over Voltage Protection）：过压保护跳闸

显示：
  电压表：当前输出电压
  电流表：当前输出电流

【操作步骤（给Arduino供电）】
1. 关闭OUTPUT（输出关闭状态）
2. 调节电压旋钮至5V（看电压表）
3. 调节电流限制至0.5A（或根据需要）
4. 将表笔（鳄鱼夹）接好目标板
5. 打开OUTPUT
6. 观察CV/CC指示，确认处于CV模式
7. 测试完毕先关OUTPUT，再断开连线

【恒流模式的应用】
给LED供电：设置电流为LED额定值（如10mA）
恒流充电：给电池用恒流模式充电
测量元件阈值：通过CC模式观察元件两端电压

【过流保护测试（"折回"特性）】
短路测试：
1. 调限流电流为0.1A
2. 输出端短路
3. 电源进入CC模式，此时电流被限制在0.1A
4. 电压降为零（或接近零）
5. 此为正常保护，移除短路后恢复

【常见型号】
单通道：
  MASTECH HY3005D（0~30V/5A）：国产经典，性价比高
  UNI-T UTP3315TFL（0~32V/3A）

第五章  频率与时间测量
================================================================

--------------------------------------------------------------
5.1  频率计
--------------------------------------------------------------

【原理】
计数特定时间内的信号脉冲数
频率 = 计数值 / 闸门时间
精度取决于内部时基晶振

【参数】
频率范围：通常DC到数GHz
分辨率：0.1Hz~1Hz（低端），0.001Hz（高精度）
测量时间（闸门时间）：越长精度越高，响应越慢
时基精度：普通±5ppm，TCXO±0.5ppm，OCXO±0.01ppm
输入阻抗：1MΩ（低频通道）或50Ω（高频通道）

【使用】
低频通道（<100MHz）：1MΩ输入，可直接连接电路
高频通道（>100MHz）：50Ω输入，需要50Ω信号源或衰减器

测量周期：1/频率
测量占空比：脉宽/周期
测频注意：信号幅度要足够触发内部比较器（通常>100mVpp）

【常见型号】
UNI-T UT622（600MHz），UNI-T UT622C
Keysight 53230A（350MHz，高精度）

第七章  频谱分析仪
================================================================

【功能】
将信号分解为频率分量，显示"频率-功率"图
找出噪声源，测量谐波，分析调制信号
是无线通信、EMC工程师必备工具

【主要参数】
频率范围：9kHz~3GHz（典型经济型），到50GHz（专业）
分辨率带宽（RBW）：越窄，频率分辨率越高，扫描越慢
参考电平：Y轴顶端功率值，单位dBm
输入阻抗：50Ω
动态范围：可测量最强和最弱信号的比值

【主要控制】
CENTER FREQ（中心频率）：显示区域中央的频率
SPAN（频率跨度）：显示的频率范围
RBW（分辨率带宽）：频率分辨率，通常自动与SPAN联动
REF LEVEL（参考电平）：调整Y轴使信号居中
MARKER（标记）：读取特定频率点的精确功率

【使用步骤（测量PWM开关电源EMI）】
1. 天线或探头接SA输入
2. 设置频率范围（如150kHz~30MHz）
3. 调RBW（如9kHz，EMC标准测量带宽）
4. 调参考电平使波形居中
5. 使用MARKER查看各峰值的频率和幅度
6. 与EMC限制线对比

【注意事项】
输入不能超过最大输入功率（通常+30dBm = 1W）
测强信号时必须用衰减器
连接射频接头用SMA/N型，避免用普通夹子

【常见型号】
经济入门：
  Rigol DSA815（9kHz~1.5GHz）：￥约3000+
  Siglent SSA3021X（9kHz~2.1GHz）
专业：
  Keysight N9320B（9kHz~3GHz）
  R&S FSV（高端，多种频率范围）

第九章  焊接工具
================================================================

--------------------------------------------------------------
9.1  电烙铁与焊台
--------------------------------------------------------------

【烙铁类型】

固定功率烙铁（直插式）：
  25W/40W/60W等固定功率
  无温控，简单低成本
  缺点：温度不稳定，易烫坏元件或焊接不良

调温焊台（最推荐）：
  内部有热电偶反馈，PID控温
  温度设定范围：200°C~480°C
  优点：温度稳定，可重复性好

常见型号：
  白光（HAKKO）936/888D（仿制品）：国内极常见，性价比高
  正品HAKKO FX-888D：日本品牌，耐用性好
  JBC（西班牙）：最高端，响应快，烙铁头耐用
  Quick 203H：国产中档
  Aixun T3A/T245A：高性价比数字调温焊台

【烙铁头类型】
刀形（K型）：适合拖焊QFP/贴片IC，切割焊锡
圆锥形（尖头）：细引脚，精细焊接
圆锥斜切（BC2/BC3）：通用型，平衡热量传导
凿形/Chisel（D形）：大功率焊点，导热快
细尖（1C/2C）：0402以下细贴片

烙铁头保养：
  焊接后及时擦锡（用烙铁头清洁海绵或铜网）
  长时间不用降温至200°C或关机
  存储时镀上一层新鲜焊锡保护
  烙铁头氧化发黑：用清洁剂恢复，或用砂纸轻磨（应急）

【焊锡选择】
有铅焊锡（Sn63/Pb37）：
  熔点183°C，熔化区间窄，流动性好
  表面光亮，易辨别焊接质量
  适合学习/维修，焊接温度280~320°C

无铅焊锡（Sn96.5/Ag3/Cu0.5，SAC305）：
  熔点约217~221°C，流动性稍差
  符合RoHS环保要求，工业生产标准
  焊接温度需更高（320~360°C）

细焊锡丝（0.5mm~0.8mm）：适合贴片精细焊接
粗焊锡丝（1.0mm~1.2mm）：适合插件焊接和大焊盘

助焊剂（Flux）：
  松香：传统，无腐蚀，焊后留有残渣（可用酒精清洗）
  水溶性助焊剂：活性强，焊后需水洗
  免洗助焊剂：现代贴片生产常用，轻度残渣
  助焊膏（Flux Paste）：SMD焊接，BGA返修使用

【插件焊接标准操作】
1. 烙铁预热至280°C（有铅），300°C（无铅）
2. 清洁烙铁头（在海绵或铜网上擦拭）
3. 元件插入PCB孔，确认方向
4. 烙铁头同时接触焊盘和引脚（约45°角）
5. 1~2秒后送入焊锡（送到焊盘/引脚接触处，不要送到烙铁头上）
6. 焊锡熔化填充焊盘后（见光亮）撤焊锡
7. 再等0.5秒，撤烙铁
8. 不要吹气冷却（导致冷焊），自然冷却
9. 检查焊点：光亮，圆润，填满焊盘，无桥接，无虚焊

【贴片焊接操作（手工）】
以SOT-23晶体管为例：
1. 固定PCB
2. 其中一个焊盘上先点少量焊锡
3. 用镊子夹持元件放到焊盘上，确认方向
4. 烙铁加热已预锡焊盘，固定元件（临时固定）
5. 焊接其余引脚（正常焊接方式）
6. 最后重新加热第一个引脚，补充适量焊锡

以TQFP/QFP（细间距IC）为例（拖焊法）：
1. IC放好，用胶带或手指固定对准
2. 先焊4个角的引脚固定IC
3. 在所有引脚上涂助焊剂
4. 用刀形烙铁头蘸适量焊锡
5. 沿引脚方向缓慢"拖"过所有引脚
6. 多余焊锡用吸锡线或补充助焊剂拖走
7. 逐个检查，用放大镜确认无桥接

--------------------------------------------------------------
9.2  热风焊台（热风枪）
--------------------------------------------------------------

【用途】
SMD元件返修（拆焊贴片IC，尤其QFN/BGA）
拆卸贴片元件
锡膏回流焊（小批量）

【参数】
温度范围：100°C~500°C
风量调节：决定加热区域和对周边元件影响
风嘴尺寸：多种规格，对应不同元件大小

【操作（拆除SOT-23）】
1. 在元件上涂少量助焊剂
2. 热风枪预热（通常350~380°C，风量2~3）
3. 风嘴距元件1~1.5cm，圆周运动
4. 约5~10秒后，焊锡熔化（元件变亮）
5. 用镊子轻轻取下（不可强掰，等焊锡真正熔化）

【操作（拆除QFN/LGA）】
难点：底部焊盘，看不到焊锡是否熔化
1. 充分涂助焊剂
2. 较高温度（400°C）和较大风量
3. 加热更长时间（30~60秒）
4. 用镊子沿角方向轻刮试探，感觉松动即可取下
5. 清理焊盘上残余焊锡（吸锡线+助焊剂）

【注意事项】
保护周边元件（铝箔，耐热胶带）
不要对准IC直吹（集中风嘴均匀加热）
PCB反面注意，过热可能导致PCB起泡

--------------------------------------------------------------
9.3  回流焊
--------------------------------------------------------------

用于量产或自制PCB批量贴片焊接
焊膏印刷→贴片→回流炉加热→冷却
自制回流炉：改装烤箱/电热板+温控
温度曲线（有铅）：预热150°C×60s，回流183°C以上×45s，峰值约215°C

第十章  其他常用工具

--------------------------------------------------------------
10.1  面包板（无焊试验板）
--------------------------------------------------------------

【结构】
中间两列：每列5孔纵向连通，对应一个元件行
两侧电源轨：横向全部连通（+和-）

【使用注意】
连线尽量短，减少感抗
高频信号避免用面包板（寄生电容影响大）
同列相邻孔电气连通，跨中间沟槽不连通
电源轨通常只有一半连通（中间有断开），两半需短接

--------------------------------------------------------------
10.2  探针与夹具
--------------------------------------------------------------

测试夹（鳄鱼夹/文件夹）：连接大焊盘或测试点
探针（测试钩）：钩住IC引脚
IC测试夹：夹住整块DIP IC进行在线测试
锁针（Spring Loaded Pin / Pogo Pin）：自制测试夹具

--------------------------------------------------------------
10.3  防静电设备（ESD保护）
--------------------------------------------------------------

CMOS和MOSFET极其敏感，静电可瞬间击穿氧化层
ESD防护措施：
  防静电腕带：佩戴并连接到地（接地参考）
  防静电垫（工作台垫）：软垫+接地
  防静电存储袋（银色袋）：存放和运输芯片
  防静电镊子：非磁性，导电
操作规则：
  拿IC前先触摸接地的金属
  不要接触IC引脚金属部分
  芯片放在防静电泡沫中

--------------------------------------------------------------
10.4  放大镜与显微镜
--------------------------------------------------------------

手持放大镜（5×~10×）：基本检查焊点
台式放大镜（LED照明）：长时间焊接使用，减少眼睛疲劳
数字显微镜（USB，7×~45×或200×）：
  连接电脑显示，观察焊点和PCB走线
  适合检查0402以下元件，SMD密脚IC
  价格：国产几百元可用
体式显微镜（三目）：
  专业返修必备，30×~45×
  辨别细微焊接缺陷（冷焊，桥接，开路）
  价格：几千元起
