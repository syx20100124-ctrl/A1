第一章  电阻（R）
================================================================

--------------------------------------------------------------
1.1  基本定义
--------------------------------------------------------------

欧姆定律：
  V = I × R
  I = V / R
  R = V / I

单位：欧姆（Ω），1kΩ = 1000Ω，1MΩ = 1000kΩ

--------------------------------------------------------------
1.2  物理结构公式
--------------------------------------------------------------

导体电阻由材料和几何形状决定：

  R = ρ × L / A

  其中：
    ρ = 电阻率（Ω·m），材料本身属性
        铜：ρ ≈ 1.72 × 10⁻⁸ Ω·m
        铝：ρ ≈ 2.82 × 10⁻⁸ Ω·m
        硅（n型掺杂后）：ρ ≈ 10⁻³~10⁴ Ω·m（可变）
        碳膜：ρ ≈ 10⁻⁵ Ω·m（典型）
    L = 导体长度（m）
    A = 导体截面积（m²）

温度对电阻的影响：
  R(T) = R₀ × [1 + α × (T - T₀)]

  其中：
    R₀ = 参考温度T₀（通常25°C）下的阻值
    α  = 温度系数（/°C 或 ppm/°C）
         正温度系数（PTC）：金属导体，温度升高阻值增大
         负温度系数（NTC）：半导体/碳，温度升高阻值减小
         金属膜电阻α典型：±50~±100 ppm/°C

--------------------------------------------------------------
1.3  功率公式
--------------------------------------------------------------

电阻消耗功率（全部转化为热能）：

  P = V × I
  P = I² × R       （已知电流时用）
  P = V² / R        （已知电压时用）

  三个公式等价，可互相推导。

消耗能量：
  W = P × t = V × I × t = I² × R × t = V² × t / R

实际使用降额原则：
  P_实际 ≤ P_额定 × 0.5
  即：实际功耗不超过额定功率的50%，避免过热损坏

--------------------------------------------------------------
1.4  串联电路
--------------------------------------------------------------

N个电阻串联（R₁, R₂, ..., Rₙ）：

等效电阻：
  R_总 = R₁ + R₂ + R₃ + ... + Rₙ

各电阻电流相同（串联特性）：
  I₁ = I₂ = ... = Iₙ = I_总

各电阻电压按阻值分配（分压）：
  V₁ = I × R₁
  V₂ = I × R₂
  V_总 = V₁ + V₂ + ... + Vₙ

分压公式（两电阻串联，求某电阻两端电压）：
  V₂ = V_总 × R₂ / (R₁ + R₂)
  V₁ = V_总 × R₁ / (R₁ + R₂)

  例：R₁=1kΩ，R₂=2kΩ，V_总=9V
    V₂ = 9 × 2000 / (1000 + 2000) = 6V
    V₁ = 9 × 1000 / 3000 = 3V

--------------------------------------------------------------
1.5  并联电路
--------------------------------------------------------------

N个电阻并联：

等效电阻（三种等价写法）：
  1/R_总 = 1/R₁ + 1/R₂ + ... + 1/Rₙ
  R_总 = 1 / (1/R₁ + 1/R₂ + ... + 1/Rₙ)

两电阻并联简化公式（最常用）：
  R_总 = R₁ × R₂ / (R₁ + R₂)

  例：1kΩ 并联 2kΩ：
    R_总 = 1000 × 2000 / (1000 + 2000) = 2000000 / 3000 ≈ 667Ω

N个相同电阻R并联：
  R_总 = R / N

各电阻电压相同（并联特性）：
  V₁ = V₂ = ... = Vₙ = V_总

各电阻电流按阻值反比分配（分流）：
  I₁ = V_总 / R₁
  I_总 = I₁ + I₂ + ... + Iₙ

分流公式（两电阻并联，求流过某支路的电流）：
  I₁ = I_总 × R₂ / (R₁ + R₂)
  I₂ = I_总 × R₁ / (R₁ + R₂)

  注意：分流公式中分子是对方的电阻，与分压不同！

  例：R₁=1kΩ，R₂=3kΩ，I_总=4mA
    I₁ = 4 × 3 / (1+3) = 3mA
    I₂ = 4 × 1 / (1+3) = 1mA

--------------------------------------------------------------
1.6  混联（串并联混合）
--------------------------------------------------------------

化简步骤：
1. 找出纯并联的部分，用并联公式计算等效值
2. 找出纯串联的部分，用串联公式计算
3. 重复步骤1~2，直到化简为一个电阻

  例：R₁=10Ω串联（R₂=20Ω并联R₃=20Ω）
    第一步：R₂//R₃ = 20×20/(20+20) = 10Ω
    第二步：R₁ + 10 = 10 + 10 = 20Ω

--------------------------------------------------------------
1.7  常用电阻电路公式
--------------------------------------------------------------

限流电阻（给LED串联限流）：
  R = (V_电源 - V_LED) / I_LED

  例：5V电源，红色LED（Vf=2.0V），工作电流10mA
    R = (5 - 2.0) / 0.010 = 300Ω，选330Ω

上拉电阻（Pull-up）：
  I_上拉 = V_电源 / R_上拉
  上拉强度越大（R越小），驱动能力越强，功耗越大
  典型：10kΩ（通用），4.7kΩ（I2C），1kΩ（强上拉）

下拉电阻（Pull-down）：同上拉，接到GND

惠斯通电桥平衡条件：
  R₁/R₂ = R₃/R₄   →   R₁×R₄ = R₂×R₃
  平衡时桥臂中间无电流流过，用于精密测量

第二章  电容（C）
================================================================

--------------------------------------------------------------
2.1  基本定义
--------------------------------------------------------------

电荷与电压的关系（基本定义）：
  Q = C × U      （电荷量 = 电容量 × 电压）
  C = Q / U      （电容量 = 电荷量 / 电压）
  U = Q / C

电容的电流-电压关系（动态）：
  i(t) = C × dU/dt

  含义：电容的电流等于电容量乘以电压对时间的变化率
  直流时 dU/dt = 0，故电流为0（电容阻断直流）
  电压变化越快，充放电电流越大

--------------------------------------------------------------
2.2  平行板电容器的物理推导
--------------------------------------------------------------

两平行导体板构成的理想电容器：

  C = ε × A / d

  其中：
    ε = 介质的介电常数（F/m）
        ε = ε₀ × εᵣ
        ε₀ = 真空介电常数 = 8.854 × 10⁻¹² F/m
        εᵣ = 相对介电常数（无单位），材料属性：
              真空/空气 ≈ 1.0
              聚酯薄膜 ≈ 3.2~3.6
              陶瓷（X7R）≈ 2000~4000
              铝氧化物（电解电容）≈ 7~10
              钽氧化物 ≈ 27
    A = 极板面积（m²）
    d = 极板间距（m）

  物理含义：
    极板面积越大 → 电容越大
    极板间距越小 → 电容越大
    介电常数越大（高εᵣ材料）→ 电容越大
    这就是为何陶瓷电容（高εᵣ）可以做到小体积大容量

极板间电场强度：
  E = U / d（均匀电场）
  E_max = U_max / d ≤ E_击穿（介质击穿场强）

  这决定了电容的耐压：d越大，耐压越高，但容量越小

--------------------------------------------------------------
2.3  能量储存公式
--------------------------------------------------------------

电容储存的能量（以电场形式）：

  W = ½ × C × U²
  W = Q² / (2C)
  W = ½ × Q × U

  三式等价，代入Q=CU可互相推导。

  单位：焦耳（J）
  含义：充电时，电源做的功一半存在电场中，一半……
    实际上：全部能量W = C×U²，其中一半W=½CU²存在电容中，
    另一半½CU²在充电过程中被电阻消耗（无论电阻多小！）
    这是电容充电的根本能量损耗，与电阻无关。

  例：100μF电容充到12V：
    W = 0.5 × 100×10⁻⁶ × 12² = 0.5 × 10⁻⁴ × 144 = 7.2 × 10⁻³ J = 7.2mJ

--------------------------------------------------------------
2.4  容抗（交流电路）
--------------------------------------------------------------

电容对交流信号的阻抗：

  Xc = 1 / (ω × C) = 1 / (2π × f × C)

  单位：欧姆（Ω）
  频率越高 → Xc越小 → 电容对高频信号阻碍越小（通高频）
  频率越低 → Xc越大 → 电容对低频信号阻碍越大（阻低频/直流）

  例：0.1μF电容在1kHz时的容抗：
    Xc = 1 / (2π × 1000 × 0.1×10⁻⁶) = 1591Ω ≈ 1.6kΩ

  例：0.1μF电容在100kHz时：
    Xc = 1591 / 100 = 15.9Ω（频率增大100倍，容抗减小100倍）

--------------------------------------------------------------
2.5  串联电路
--------------------------------------------------------------

N个电容串联：

等效电容（串联后总容量减小）：
  1/C_总 = 1/C₁ + 1/C₂ + ... + 1/Cₙ
  C_总 = 1 / (1/C₁ + 1/C₂ + ... + 1/Cₙ)

两电容串联简化：
  C_总 = C₁ × C₂ / (C₁ + C₂)

  规律：两电容串联，等效值小于其中较小的一个

N个相同电容C串联：
  C_总 = C / N

串联时各电容电荷量相同（串联特性）：
  Q₁ = Q₂ = ... = Qₙ = Q_总

串联时电压按容量反比分配：
  U₁ = Q / C₁
  U₂ = Q / C₂
  U_总 = U₁ + U₂ + ... + Uₙ

  小电容分得更高电压！（串联时最弱的电容最危险）

  分压公式（两电容串联）：
    U₁ = U_总 × C₂ / (C₁ + C₂)
    U₂ = U_总 × C₁ / (C₁ + C₂)

  注意：分子是对方的电容，小电容→大电压，与电阻相反！

  例：C₁=10μF，C₂=100μF，串联后接100V：
    U₁ = 100 × 100 / (10+100) ≈ 90.9V  ← 小电容承受大部分电压！
    U₂ = 100 × 10 / 110 ≈ 9.1V

  ⚠ 这就是为何电容串联使用需注意耐压分配

串联电容提升耐压：
  总耐压 ≈ 各电容耐压之和（当容量相同时，耐压均匀分配）
  容量不同时：小电容分压更大，总耐压不能简单相加
  实际应用：串联同规格电容提升耐压，需并联均压电阻

均压电阻计算（电容串联均压）：
  并联在每个电容上的均压电阻R应满足：
  I_均压 >> I_漏电
  通常 R_均压 = U_每个电容 / (10 × I_漏电_最大)

--------------------------------------------------------------
2.6  并联电路
--------------------------------------------------------------

N个电容并联：

等效电容（并联后总容量增大）：
  C_总 = C₁ + C₂ + C₃ + ... + Cₙ

  规律：直接相加，比其中最大的还大

N个相同电容C并联：
  C_总 = N × C

并联时各电容电压相同：
  U₁ = U₂ = ... = Uₙ = U_总

并联时各电容电荷量按容量分配：
  Q₁ = C₁ × U
  Q₂ = C₂ × U
  Q_总 = Q₁ + Q₂ + ... = (C₁ + C₂ + ...) × U = C_总 × U

--------------------------------------------------------------
2.7  电容充放电（RC电路过渡过程）
--------------------------------------------------------------

电路结构：
  电源Vs串联电阻R，再接电容C
  初始电容电压为U₀

充电过程（U₀ = 0，从0充到Vs）：

  时间常数：τ = R × C

  电容电压随时间变化：
    Uc(t) = Vs × (1 - e^(-t/τ))

  充电电流随时间变化：
    i(t) = (Vs / R) × e^(-t/τ)

  关键时刻：
    t = τ    → Uc = 0.632 × Vs（充到63.2%）
    t = 2τ   → Uc = 0.865 × Vs（充到86.5%）
    t = 3τ   → Uc = 0.950 × Vs（充到95.0%）
    t = 5τ   → Uc = 0.993 × Vs（充到99.3%，工程上视为充满）
    t = ∞    → Uc = Vs（完全充满）

放电过程（电源断开，初始电压U₀，通过R放电）：

  Uc(t) = U₀ × e^(-t/τ)
  i(t)  = (U₀ / R) × e^(-t/τ)  （方向与充电相反）

  关键时刻：
    t = τ  → Uc = 0.368 × U₀（剩余36.8%）
    t = 3τ → Uc = 0.050 × U₀（剩余5%）
    t = 5τ → Uc = 0.007 × U₀（剩余0.7%，工程上视为放完）

通用公式（初始值U₀，终值U∞，任意RC过渡）：
  Uc(t) = U∞ + (U₀ - U∞) × e^(-t/τ)

  这是最通用的形式，充电放电都适用，代入初值终值即可

  例：电容已充到3V，接到5V源（串1kΩ）继续充电
    U₀ = 3V，U∞ = 5V，τ = 1000 × C
    Uc(t) = 5 + (3-5) × e^(-t/τ) = 5 - 2×e^(-t/τ)
    t = τ时：Uc = 5 - 2×0.368 = 5 - 0.736 = 4.264V

  例：计算充电到目标电压所需时间
    目标：Uc = U_目标
    t = -τ × ln[(U_目标 - U∞) / (U₀ - U∞)]
    或：t = τ × ln[(U₀ - U∞) / (U_目标 - U∞)]

--------------------------------------------------------------
2.8  电容之间的电荷转移（重要！）
--------------------------------------------------------------

情景：C₁已充电到电压U₁，C₂无电（U₂=0），
      两电容通过导线（或经过电阻）并联连接。
      求：最终稳定后两电容的电压是多少？

（A）理想情况（导线直接连接，电阻=0）：

电荷守恒定律（总电荷不变）：
  Q_初 = Q_末
  C₁×U₁ + C₂×U₂ = (C₁+C₂) × U_末

  若U₂ = 0：
    U_末 = C₁×U₁ / (C₁+C₂)

  若U₂ ≠ 0：
    U_末 = (C₁×U₁ + C₂×U₂) / (C₁+C₂)

  例1：C₁=100μF充到10V，C₂=100μF无电，并联后：
    U_末 = (100×10 + 100×0) / (100+100) = 1000/200 = 5V
    （电压减半，符合直觉）

  例2：C₁=100μF充到10V，C₂=300μF无电，并联后：
    U_末 = (100×10) / (100+300) = 1000/400 = 2.5V

  例3：C₁=100μF充到10V，C₂=100μF充到4V，同极性并联：
    U_末 = (100×10 + 100×4) / (100+100) = 1400/200 = 7V

  例4（反极性连接！）：C₁=100μF/10V，C₂=100μF/4V，反极性并联：
    定义C₁正极性，C₂反接则U₂取负值：
    U_末 = (100×10 + 100×(-4)) / (100+100) = 600/200 = 3V

能量分析（理想并联，电荷转移）：
  W_初 = ½C₁U₁² + ½C₂U₂²
  W_末 = ½(C₁+C₂)U_末²
  ΔW = W_初 - W_末（损失的能量）

  当U₂=0时，损失能量：
    ΔW = ½ × C₁×C₂/(C₁+C₂) × (U₁-U₂)²
       = ½ × C₁×C₂/(C₁+C₂) × U₁²（当U₂=0）

  这部分能量无论导线电阻多小，都会被耗散（发热/火花）！
  这是理想导体直接连接时电荷转移的基本能量损失定律。

  例：C₁=C₂=100μF，U₁=10V，U₂=0：
    W_初 = ½×100×10⁻⁶×10² = 5mJ
    U_末 = 5V
    W_末 = ½×200×10⁻⁶×5² = 2.5mJ
    ΔW = 5 - 2.5 = 2.5mJ（损失了一半！）

（B）经过电阻R充电（实际电路）：

初始：C₁=U₁，C₂=0，通过串联电阻R连接

这是RC充放电的扩展版本：
  从C₁的角度：C₁放电
  从C₂的角度：C₂被充电
  等效电路：U₁串联C₁（C₁内阻看作0），串联R，接C₂

等效分析（镜像变换法）：
  将C₁等效为电压源U₁串联等效电容，
  最终稳态电压与理想情况相同：
    U_末 = C₁×U₁ / (C₁+C₂)

  过渡过程时间常数：
    τ = R × (C₁×C₂) / (C₁+C₂) = R × C_串
    即：τ = R × C₁的串联C₂的等效值

  过渡过程中电流（从C₁流向C₂）：
    i(t) = [(U₁-U_末) / R] × e^(-t/τ)
    初始最大电流 = U₁ / R（当U₂初始=0）

  过渡过程中电压（以U₂为例）：
    U₂(t) = U_末 × (1 - e^(-t/τ))

  例：C₁=100μF/10V，C₂=100μF/0V，R=100Ω串联：
    U_末 = 5V
    τ = 100 × (100μF×100μF)/(100μF+100μF) = 100 × 50μF = 5ms
    初始电流 = 10/100 = 100mA
    t=5ms时：U₂ ≈ 5 × 0.632 = 3.16V
    t=25ms时：U₂ ≈ 5V（基本充满）

（C）三个或多个电容相互充电：

多个电容并联，某些有初始电压，某些无电：
使用电荷守恒，同样适用：

  U_末 = (C₁U₁ + C₂U₂ + C₃U₃) / (C₁+C₂+C₃)

  例：C₁=100μF/12V，C₂=200μF/6V，C₃=300μF/0V，并联：
    U_末 = (100×12 + 200×6 + 300×0) / (100+200+300)
         = (1200 + 1200 + 0) / 600
         = 2400 / 600
         = 4V

（D）电容通过二极管单向充电：

若C₁和C₂之间串一个二极管（从C₁到C₂方向）：
  当U₁ > U₂ + V_f（正向压降，硅约0.7V）：二极管导通，C₂充电
  当U₁ ≤ U₂ + V_f：二极管截止，充电停止

  最终稳态：U₂ = U₁ - V_f（二极管压降导致略低）

  这就是整流和限幅电路的基本原理

--------------------------------------------------------------
2.9  滤波电路的电容计算
--------------------------------------------------------------

半波整流滤波（纹波估算）：
  ΔU ≈ I_负载 / (f × C)
  C ≈ I_负载 / (f × ΔU)

  其中：
    ΔU = 允许的纹波电压峰峰值
    f = 市电频率（50Hz）
    I_负载 = 负载电流

全波/桥式整流滤波（纹波更小）：
  ΔU ≈ I_负载 / (2f × C)
  C ≈ I_负载 / (2f × ΔU)

  例：桥式整流，负载电流500mA，允许纹波1V，50Hz：
    C = 0.5 / (2 × 50 × 1) = 0.5/100 = 0.005F = 5000μF

高频去耦电容选型（电源旁路）：
  要求：Xc ≪ Z_负载（通常Xc < Z_负载 / 10）
  C > 1 / (2π × f × (Z_负载/10))

================================================================
第三章  电感（L）
================================================================

--------------------------------------------------------------
3.1  基本定义
--------------------------------------------------------------

电感的电压-电流关系（动态）：
  V(t) = L × dI/dt

  含义：电感的电压等于电感量乘以电流对时间的变化率
  直流稳态时 dI/dt = 0，故电压为0（电感短路直流）
  电流变化越快，感应电动势越大

--------------------------------------------------------------
3.2  物理结构推导
--------------------------------------------------------------

螺线管电感量：
  L = μ × N² × A / l

  其中：
    μ = 导磁率 = μ₀ × μᵣ
        μ₀ = 4π × 10⁻⁷ H/m（真空磁导率）
        μᵣ = 相对磁导率：
              空气芯 ≈ 1
              铁粉芯 ≈ 50~80
              锰锌铁氧体 ≈ 1000~5000
              硅钢片 ≈ 1000~8000
    N = 线圈匝数
    A = 磁芯截面积（m²）
    l = 磁路长度（m）

  物理含义：
    匝数越多 → L ∝ N²（平方关系）
    截面积越大 → 磁通量越大 → L越大
    高μᵣ材料（铁芯） → L越大（同样体积下）

--------------------------------------------------------------
3.3  能量储存公式
--------------------------------------------------------------

电感储存的能量（以磁场形式）：

  W = ½ × L × I²

  单位：焦耳（J）
  电流越大，储存能量越多
  开关断开瞬间，这些能量必须有地方泄放（否则产生高压）

感应反电动势（断开电感时）：
  V_感应 = -L × dI/dt

  断开速度越快（dI/dt越大），反电动势越高
  这就是为什么继电器线圈、电机断开时会产生高压尖峰
  解决方法：并联续流二极管（Flyback Diode）

--------------------------------------------------------------
3.4  感抗（交流电路）
--------------------------------------------------------------

电感对交流信号的阻抗：

  XL = ω × L = 2π × f × L

  频率越高 → XL越大 → 电感对高频信号阻碍越大（阻高频）
  频率越低 → XL越小 → 电感对低频/直流阻碍越小（通低频）

  与电容相反：电容通高频，电感通低频

  例：1mH电感在1kHz时：
    XL = 2π × 1000 × 0.001 = 6.28Ω

  例：1mH电感在100kHz时：
    XL = 2π × 100000 × 0.001 = 628Ω

--------------------------------------------------------------
3.5  串联电路
--------------------------------------------------------------

N个电感串联（无互感）：
  L_总 = L₁ + L₂ + ... + Lₙ   （直接相加，同电阻串联）

有互感的两电感串联：
  L_总 = L₁ + L₂ ± 2M

  其中M为互感系数，± 取决于磁场方向：
    同向串联（助磁）：L_总 = L₁ + L₂ + 2M
    反向串联（去磁）：L_总 = L₁ + L₂ - 2M

互感系数：
  M = k × √(L₁ × L₂)

  k = 耦合系数（0~1），k=1为理想耦合（变压器）

--------------------------------------------------------------
3.6  并联电路
--------------------------------------------------------------

N个电感并联（无互感）：
  1/L_总 = 1/L₁ + 1/L₂ + ... + 1/Lₙ  （同电阻并联）

两电感并联：
  L_总 = L₁ × L₂ / (L₁ + L₂)

--------------------------------------------------------------
3.7  电感充放电（RL电路过渡过程）
--------------------------------------------------------------

时间常数：
  τ = L / R

  注意：R和τ的关系与RC电路相反（R越大，τ越小）

通电（从0到稳态）：
  i(t) = (V / R) × (1 - e^(-t/τ)) = I_∞ × (1 - e^(-t/τ))

  I_∞ = V/R（最终稳定电流，仅由R决定）

断电（初始电流I₀，通过R放电）：
  i(t) = I₀ × e^(-t/τ)
  V_R(t) = I₀ × R × e^(-t/τ)（电阻两端电压）

  断电瞬间（t=0+）的感应电压：
    V_感应 = I₀ × R（与电源电压方向相同，可能很高！）

--------------------------------------------------------------
3.8  品质因数Q
--------------------------------------------------------------

电感的品质因数（越高越好）：
  Q = XL / R_series = ωL / R_s = 2πfL / R_s

  R_s = 绕线的直流电阻DCR
  Q越大，能量损耗越小，谐振特性越好

--------------------------------------------------------------
3.9  变压器
--------------------------------------------------------------

理想变压器基本公式（匝数比）：

  N₁/N₂ = V₁/V₂ = I₂/I₁

  其中下标1为初级，2为次级

  电压比等于匝数比：
    V₂ = V₁ × (N₂/N₁)

  电流比与匝数比相反（功率守恒）：
    I₂ = I₁ × (N₁/N₂)

  功率守恒（理想无损）：
    P₁ = P₂   →   V₁×I₁ = V₂×I₂

阻抗变换：
  Z₁/Z₂ = (N₁/N₂)²

  即：阻抗变换比等于匝数比的平方

  例：初级接音频放大器（输出阻抗8Ω），次级接喇叭（8Ω）：
    需要N₁:N₂ = √(8/8) = 1:1，无需变换
    若放大器输出阻抗600Ω，接8Ω喇叭：
    N₁:N₂ = √(600/8) = √75 ≈ 8.66:1（降压变压器）

实际变压器效率：
  η = P₂ / P₁ × 100%（通常85%~98%）

================================================================
第四章  RLC谐振电路
================================================================

--------------------------------------------------------------
4.1  串联谐振
--------------------------------------------------------------

电路：R, L, C 串联

谐振频率（电抗为零，阻抗最小）：
  f₀ = 1 / (2π × √(L×C))
  ω₀ = 1 / √(L×C)

谐振时：
  XL = XC（感抗等于容抗）
  总阻抗 Z = R（纯阻，最小）
  电流最大：I = V/R
  电容/电感两端电压可能远超电源电压（谐振升压）

品质因数（决定谐振峰值和带宽）：
  Q = ω₀L / R = 1/(ω₀CR) = (1/R) × √(L/C)

谐振时元件电压（电压谐振，谐振升压）：
  V_L = V_C = Q × V_源

  例：Q=10，V_源=1V时，电容电压高达10V！

带宽：
  BW = f₀ / Q（Hz）
  Q越高，带宽越窄，选频特性越好

--------------------------------------------------------------
4.2  并联谐振
--------------------------------------------------------------

电路：R, L, C 并联

谐振频率（同串联）：
  f₀ = 1 / (2π × √(L×C))

谐振时：
  总阻抗最大（并联阻抗极大）
  总电流最小
  Q = R / (ω₀L) = R × ω₀C = R × √(C/L)

  用于带通滤波，谐振时阻抗最大，信号最强

--------------------------------------------------------------
4.3  常用滤波器截止频率
--------------------------------------------------------------

RC低通滤波器（-3dB截止频率）：
  f_c = 1 / (2π × R × C)
  在f_c处，输出幅度下降到输入的0.707（-3dB）

  例：R=10kΩ，C=0.01μF：
    f_c = 1 / (2π × 10000 × 0.00000001) = 1591Hz ≈ 1.6kHz

RC高通滤波器：
  f_c = 1 / (2π × R × C)（同低通，但高于f_c才通过）

RL低通滤波器：
  f_c = R / (2π × L)

================================================================
第五章  二极管
================================================================

--------------------------------------------------------------
5.1  理想二极管模型
--------------------------------------------------------------

简化模型：
  正偏时：导通，压降 Vf = 0（理想）
  反偏时：截止，电流 I = 0

实用模型（含恒压降）：
  正偏时：Vf = 0.7V（硅），0.3V（锗），0.3~0.4V（肖特基）
  导通后：V_负载 = V_源 - Vf

--------------------------------------------------------------
5.2  肖克利二极管方程（物理精确）
--------------------------------------------------------------

  I = I_s × (e^(V/nVT) - 1)

  其中：
    I_s = 反向饱和电流（约10⁻¹²~10⁻⁹ A，随温度强烈增加）
    n   = 理想因子（1~2，硅二极管约1.1~1.5）
    VT  = 热电压 = k×T/q ≈ 26mV（在25°C时）
          k = 玻尔兹曼常数 = 1.38×10⁻²³ J/K
          T = 绝对温度（K）
          q = 电子电荷 = 1.6×10⁻¹⁹ C

  温度影响：
    每升高10°C，I_s约增加一倍（双倍规则）
    同电流下，正向压降每升高1°C，减小约2mV
    这就是二极管（和BJT）的温度漂移来源

--------------------------------------------------------------
5.3  整流电路计算
--------------------------------------------------------------

半波整流（单个二极管）：
  V_直流平均值 = V_峰值 / π ≈ 0.318 × V_峰值
  V_峰值 = V_有效值 × √2 ≈ 1.414 × V_有效值
  二极管承受最大反向电压 = V_峰值（需PIV > V_峰值）

全波整流（中心抽头变压器或桥式）：
  桥式整流 V_直流平均值 = 2 × V_峰值 / π ≈ 0.636 × V_峰值
  每个二极管承受最大反向电压 = V_峰值

  例：220V交流，桥式整流：
    V_峰值 = 220 × 1.414 = 311V
    V_直流 ≈ 0.636 × 311 ≈ 198V（理想，不含压降和滤波纹波）
    每个二极管PIV至少需要311V（选耐压400V以上）

--------------------------------------------------------------
5.4  稳压管（齐纳）电路计算
--------------------------------------------------------------

稳压电路：Vs → R_串联 → Vz（稳压管并联负载RL）

稳压条件：
  I_z_min ≤ I_z ≤ I_z_max

限流电阻计算：
  R = (Vs - Vz) / (I_z + I_L)

  其中 I_L = Vz / R_L（负载电流）

  R的范围（保证稳压）：
    R_max = (Vs_min - Vz) / (I_z_min + I_L_max)
    R_min = (Vs_max - Vz) / (I_z_max + I_L_min)

稳压管功耗：
  P_z = Vz × I_z
  需满足 P_z ≤ P_z_max

================================================================
第六章  晶体管（BJT）
================================================================

--------------------------------------------------------------
6.1  基本公式
--------------------------------------------------------------

电流关系（NPN，放大区）：
  I_C = β × I_B = hFE × I_B
  I_E = I_C + I_B = (β+1) × I_B
  I_C = α × I_E        （α = β/(β+1) ≈ 0.99~0.999）

β（hFE）与α的关系：
  β = α / (1-α)
  α = β / (β+1)

基极-发射极结压降（典型值）：
  V_BE ≈ 0.6~0.7V（硅NPN，正常偏置，25°C）
  V_BE_sat ≈ 0.7~0.8V（饱和时，I_B更大）
  V_CE_sat ≈ 0.1~0.3V（饱和时集射间压降）

温度对V_BE的影响：
  ΔV_BE / ΔT ≈ -2mV/°C
  即温度每升高1°C，V_BE减小约2mV

--------------------------------------------------------------
6.2  工作区判断
--------------------------------------------------------------

NPN晶体管：
  截止区：V_BE < 0.5V，I_C ≈ 0，I_B ≈ 0
  放大区：V_BE ≈ 0.7V，V_CE > V_CE_sat，I_C = β×I_B
  饱和区：V_BE > 0.7V，V_CE ≈ 0.2V，I_C < β×I_B

--------------------------------------------------------------
6.3  共射极放大器直流偏置
--------------------------------------------------------------

分压偏置电路（最稳定的偏置方式）：
  R₁（接Vcc），R₂（接地）分压提供V_B
  R_C（集电极到Vcc），R_E（发射极到地）

步骤1：设定静态工作点
  通常设：I_C_Q ≈ I_c_max / 2（留对称摆幅）
  V_CE_Q ≈ Vcc / 2（留最大摆幅）

步骤2：确定V_E（发射极直流电压）
  一般取 V_E = 0.1 × Vcc（留10%给反馈稳定）
  R_E = V_E / I_E_Q ≈ V_E / I_C_Q（I_E ≈ I_C）

步骤3：确定R_C
  V_RC = Vcc - V_CE_Q - V_E = Vcc/2 - V_E（近似）
  R_C = V_RC / I_C_Q

步骤4：确定V_B（基极直流电压）
  V_B = V_E + V_BE = V_E + 0.7V

步骤5：确定R₁和R₂
  分压器电流 I_分压 >> I_B（通常取I_分压 = 10×I_B_Q）
  I_B_Q = I_C_Q / β
  R₂ = V_B / I_分压
  R₁ = (Vcc - V_B) / I_分压

交流电压增益：
  Av = -g_m × R_C'   （负号表示反相）
  g_m = I_C_Q / V_T = I_C_Q / 0.026（跨导，A/V）
  R_C' = R_C // R_L（考虑负载并联）

输入阻抗：
  R_in = R₁ // R₂ // (β+1)×r_e
  r_e = V_T / I_E_Q = 26mV / I_E_Q

输出阻抗：
  R_out ≈ R_C

--------------------------------------------------------------
6.4  开关模式（数字驱动）
--------------------------------------------------------------

BJT作为开关（饱和/截止）：

饱和条件：
  I_B ≥ I_C_sat / β_min × （强制饱和系数，通常取5~10倍）
  I_B_min = I_C_sat / β_min
  R_B = (V_驱动 - V_BE) / I_B

  例：用5V信号，通过BJT驱动12V/100mA继电器，β=100：
    I_C_sat = 100mA
    I_B_min = 100mA / 100 = 1mA
    取I_B = 5×I_B_min = 5mA（强制饱和）
    R_B = (5V - 0.7V) / 5mA = 4.3V / 5mA = 860Ω，选820Ω

================================================================
第七章  场效应管（MOSFET）
================================================================

--------------------------------------------------------------
7.1  基本工作区
--------------------------------------------------------------

N沟道增强型MOSFET：

截止区（V_GS < V_th）：
  I_D ≈ 0（关断）

线性区（V_GS > V_th，V_DS < V_GS - V_th）：
  I_D = μ_n×Cox×(W/L) × [(V_GS-V_th)×V_DS - V_DS²/2]
  简化为：I_D ≈ R_DS(on)_等效的欧姆特性（开关模式用）

饱和区（V_GS > V_th，V_DS > V_GS - V_th）：
  I_D = ½×μ_n×Cox×(W/L) × (V_GS-V_th)²
      = K × (V_GS-V_th)²
  K = ½×μ_n×Cox×(W/L)（过程参数，由制造决定）

--------------------------------------------------------------
7.2  开关模式计算
--------------------------------------------------------------

导通损耗：
  P_导通 = I_D² × R_DS(on)

开关损耗（上升下降时的能量损耗）：
  P_开关 = ½ × V_DS × I_D × (t_r + t_f) × f
  t_r = 上升时间，t_f = 下降时间，f = 开关频率

栅极驱动功率：
  P_G = Q_g × V_GS × f
  Q_g = 总栅极电荷（手册给出），V_GS = 驱动电压

总损耗：
  P_总 = P_导通 + P_开关 + P_G

结温估算：
  T_j = T_ambient + P_总 × R_θJA
  R_θJA = 结到环境的热阻（手册给出，°C/W）

--------------------------------------------------------------
7.3  MOSFET体二极管
--------------------------------------------------------------

每个MOSFET内部都有寄生体二极管（由结构决定）：
  N沟道MOSFET：体二极管从源极（S）指向漏极（D）
  正向导通条件：V_S > V_D（源极比漏极电压高约0.7V）
  额定电流与MOSFET漏极电流相当
  恢复时间通常较慢（500ns~几μs），同步整流时需注意

================================================================
第八章  运算放大器（Op-Amp）
================================================================

--------------------------------------------------------------
8.1  理想运放分析法（虚短、虚断）
--------------------------------------------------------------

虚短（Virtual Short）：
  V+ = V-（两输入端电压相等）
  成立条件：运放处于线性区，有负反馈

虚断（Virtual Open）：
  I+ = I- = 0（两输入端电流为零）
  成立条件：理想运放输入阻抗无穷大

用这两条规则可以推导所有基本运放电路。

--------------------------------------------------------------
8.2  基本运放电路公式
--------------------------------------------------------------

同相放大器（Non-inverting Amplifier）：
  V_out = V_in × (1 + R_f/R₁)
  增益 Av = 1 + R_f/R₁（≥1，不能小于1）
  输入阻抗极高（≈运放本身输入阻抗，MΩ~GΩ）
  输出阻抗极低（≈运放输出阻抗/开环增益）

反相放大器（Inverting Amplifier）：
  V_out = -V_in × (R_f/R₁)
  增益 Av = -R_f/R₁（负号表示反相）
  输入阻抗 = R₁
  输出阻抗极低

电压跟随器（Voltage Follower / Buffer）：
  V_out = V_in（增益=1）
  R_f = 0，R₁ = ∞（或去掉R₁，R_f短路）
  特点：超高输入阻抗，超低输出阻抗，阻抗变换

加法器（Summing Amplifier，反相输入）：
  V_out = -R_f × (V₁/R₁ + V₂/R₂ + V₃/R₃)
  当R₁=R₂=R₃=R时：
    V_out = -(R_f/R) × (V₁ + V₂ + V₃)

差分放大器（Differential Amplifier）：
  V_out = (R_f/R₁) × (V₂ - V₁)
  要求：R₁'/R₂' = R₁/R_f（各电阻精确匹配，否则共模误差大）

积分器（Integrator）：
  V_out = -(1/(R×C)) × ∫V_in dt
  对方波积分→三角波，对正弦积分→余弦

微分器（Differentiator）：
  V_out = -R×C × dV_in/dt
  对三角波微分→方波
  注意：微分器容易振荡，实际需串联小电阻限带宽

仪表放大器（Instrumentation Amplifier）：
  V_out = (1 + 2R₁/R_G) × (V₂ - V₁)
  R_G = 增益设置电阻（外接）
  高CMRR（共模抑制比），适合传感器信号放大

--------------------------------------------------------------
8.3  比较器计算
--------------------------------------------------------------

基本比较器：
  V+ > V- → 输出高（正饱和，接近V+）
  V+ < V- → 输出低（负饱和，接近V-或GND）

施密特触发（迟滞比较器）：
  防止噪声引起多次翻转，设定上下门限

  同相施密特：
    V_TH（上门限）= V_ref + (V_out_H - V_ref) × R₁/(R₁+R₂)
    V_TL（下门限）= V_ref + (V_out_L - V_ref) × R₁/(R₁+R₂)
    迟滞量 ΔV = V_TH - V_TL

  反相施密特：
    V_TH = V_ref × (R₁+R₂)/R₂ - V_out_L × R₁/R₂（稍复杂）

----------------------------------------------------------------
8.4  GBW（增益带宽积）
----------------------------------------------------------------

  GBW = Av × f_-3dB = 常数（闭环增益与带宽之积不变）

  增益越高 → 带宽越小
  增益越低 → 带宽越大

  例：LM358的GBW = 1MHz
    增益=1时，带宽=1MHz
    增益=10时，带宽=100kHz
    增益=100时，带宽=10kHz

  验证运放是否够用：
    所需带宽 f_s × 增益 ≤ GBW

================================================================
第九章  功率与热设计计算
================================================================

--------------------------------------------------------------
9.1  功率计算汇总
--------------------------------------------------------------

直流功率：P = V × I = I²R = V²/R

交流有效值（RMS）：
  正弦波：V_rms = V_peak / √2 ≈ 0.707 × V_peak
  方波（占空比D）：V_rms = V_peak × √D
  三角波：V_rms = V_peak / √3 ≈ 0.577 × V_peak

交流功率：
  有功功率（真实消耗）：P = V_rms × I_rms × cosφ（W）
  视在功率：S = V_rms × I_rms（VA）
  无功功率：Q = V_rms × I_rms × sinφ（VAR）
  功率因数：PF = cosφ = P/S

分贝（dB）功率：
  N_dB = 10 × log₁₀(P₂/P₁)
  N_dB = 20 × log₁₀(V₂/V₁)（电压分贝）

  常用dB对照：
    0dB = 1倍（不变）
    3dB ≈ 2倍功率，1.414倍电压
    6dB ≈ 4倍功率，2倍电压
    10dB = 10倍功率，3.16倍电压
    20dB = 100倍功率，10倍电压
    -3dB = 0.5倍功率，0.707倍电压（-3dB截止频率定义）

--------------------------------------------------------------
9.2  散热计算
--------------------------------------------------------------

热欧姆定律（热量与电路类比）：
  ΔT = P × R_θ

  其中：
    ΔT = 温差（°C）
    P  = 散热功率（W）
    R_θ = 热阻（°C/W）

热阻串联（结→壳→散热片→空气）：
  R_θJA = R_θJC + R_θCS + R_θSA

  R_θJC = 结到外壳（器件参数，手册给出）
  R_θCS = 外壳到散热片（导热硅脂，约0.1~1.0°C/W）
  R_θSA = 散热片到空气（散热片规格，平方cm越大越小）

结温计算（判断是否超温）：
  T_j = T_ambient + P × R_θJA
  必须：T_j < T_j_max（手册给出，通常125°C或150°C）

散热片选型：
  R_θSA_需要 = (T_j_max - T_ambient) / P - R_θJC - R_θCS
  选散热片的R_θSA ≤ 计算值

  例：功率管耗散5W，环境温度40°C，T_j_max=125°C：
    R_θJC = 2°C/W（手册）
    R_θCS = 0.5°C/W（含导热硅脂）
    R_θSA_需要 = (125-40)/5 - 2 - 0.5 = 17 - 2.5 = 14.5°C/W
    选R_θSA ≤ 14.5°C/W的散热片

================================================================
第十章  基尔霍夫定律与基本分析
================================================================

--------------------------------------------------------------
10.1  基尔霍夫电流定律（KCL）
--------------------------------------------------------------

在任一节点，流入电流之和 = 流出电流之和
  ΣI_流入 = ΣI_流出
  或：ΣI = 0（流入取正，流出取负）

--------------------------------------------------------------
10.2  基尔霍夫电压定律（KVL）
--------------------------------------------------------------

沿任一闭合回路，电压升之和 = 电压降之和
  ΣV = 0（顺时针绕行，升压取正，降压取负）

--------------------------------------------------------------
10.3  戴维南定理
--------------------------------------------------------------

任意含源线性网络，对外等效为：
  Vth（开路电压）串联 Rth（等效内阻）

求Vth：断开负载，计算开路端电压
求Rth：将所有电源置零（电压源短路，电流源开路），计算端口等效电阻

--------------------------------------------------------------
10.4  诺顿定理
--------------------------------------------------------------

同戴维南，等效为：
  Isc（短路电流）并联 Rth

  Isc = Vth / Rth（两种定理等效）

--------------------------------------------------------------
10.5  叠加定理
--------------------------------------------------------------

线性电路中，多个电源共同作用的响应
= 各电源单独作用时的响应之和

步骤：
1. 保留一个电源，其他置零（电压源短路，电流源开路）
2. 计算该电源单独作用时各支路电流/电压
3. 对所有电源重复，最终代数叠加

注意：叠加定理不适用于功率计算（P = I²R，非线性叠加）

--------------------------------------------------------------
10.6  最大功率传输定理
--------------------------------------------------------------

当负载电阻 R_L = R_th（内阻）时，负载获得最大功率

  P_max = Vth² / (4 × Rth)

  此时效率仅50%（一半功率消耗在内阻上）
