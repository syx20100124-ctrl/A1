第5章  运算放大器——模拟电路的瑞士军刀
================================================================

5.1  运放是什么
--------------------------------

运算放大器（简称运放，Op-Amp）是一个集成电路，
里面有几十个晶体管，对外只引出几个引脚：

  V+（同相输入端）
  V-（反相输入端）
  Vout（输出端）
  VCC+（正电源）
  VCC-（负电源或地）

运放的基本功能：
  把两个输入端的微小电压差，放大成大电压输出。
  放大倍数（开环增益）极大，通常10万倍以上。

但是……直接用开环运放基本没法用，
因为增益太大，稍微有点偏差输出就到头了。

实际应用中，我们用"反馈"来控制放大倍数。
这就是接下来要讲的各种运放电路。


5.2  两个"黄金法则"（帮助分析运放电路）
--------------------------------

只要运放加了负反馈（输出接回到V-），
就可以用这两条规则来分析：

  【黄金法则一：虚短】
  V+ ≈ V-（两个输入端电压几乎相等）

  【黄金法则二：虚断】
  运放输入端几乎不取用电流
  （输入阻抗极高，可以当做不取电流）

记住这两条，你就能分析所有常见运放电路。


5.3  同相放大器
--------------------------------

电路连接：
  输入信号 Vin → V+（同相端）
  输出 Vout → 分压后接 V-（反相端）
  分压用两个电阻：R1（接地）和R2（接输出）

放大倍数公式：
  Vout = Vin × (1 + R2/R1)

例：R1 = 1kΩ，R2 = 9kΩ
  增益 = 1 + 9/1 = 10倍
  输入100mV → 输出1V

特点：
  · 增益 ≥ 1（不能衰减，只能放大）
  · 输入阻抗高（不影响信号源）
  · 输出阻抗低（带负载能力强）


5.4  反相放大器
--------------------------------

电路连接：
  输入信号 Vin → R1 → V-（反相端）
  V+ → 接地
  R2 从输出接回到 V-

放大倍数公式：
  Vout = -Vin × (R2/R1)

（负号表示输出相位和输入相反，即倒相）

例：R1 = 1kΩ，R2 = 10kΩ
  增益 = -10
  输入 +0.5V → 输出 -5V
  输入 -0.5V → 输出 +5V

特点：
  · 可以做比例放大，也可以做衰减（R2 < R1）
  · 有倒相（180°相位翻转）
  · 输入阻抗 = R1（比同相低一些）


5.5  电压跟随器（缓冲器）
--------------------------------

电路连接：
  输入信号 Vin → V+
  输出 Vout 直接接回 V-
  （R2=0，R1=无穷大的特殊同相放大器）

特点：
  · 增益 = 1（输出等于输入）
  · 输入阻抗极高，输出阻抗极低

用途：
  传感器信号往往信号源内阻很大，
  直接连接会导致电压被拉低。
  加一个跟随器，信号不失真，
  同时获得强大的驱动能力。

  就像机床里的信号隔离器：
  弱信号进，放大后的强信号出，但值不变。


5.6  比较器——判断大小
--------------------------------

比较器和运放很像，但用途不同：
  · 运放：线性放大
  · 比较器：输出只有两种状态（高/低）

用开环运放当比较器：
  V+ > V-  → 输出高电平（VCC）
  V+ < V-  → 输出低电平（GND）

实际应用举例：温控电路
  热敏电阻分压 → V+
  基准电压（设定温度对应电压）→ V-
  温度超过设定值 → V+ > V- → 输出高电平 → 触发风扇/报警

常用比较器芯片：LM393（双路）、LM339（四路）
这两个芯片很便宜，工控项目里大量使用。


5.7  常用运放芯片选型
--------------------------------

【LM358】
  · 双路运放，单电源（可以只用+5V工作）
  · 价格极低，1块钱以内
  · 用于低频信号处理、传感器放大
  · 新手入门首选

【LM324】
  · 四路运放，单电源
  · 比LM358多两路，适合多通道应用
  · 同样便宜

【TL071 / TL081】
  · 低噪声，适合音频
  · 需要正负双电源

【OP07】
  · 精密运放，低失调
  · 用于精密测量、仪表放大

【新手建议】
  先用LM358练手。
  它工作在3V-32V单电源，接线简单，不容易坏。


【本章小结】
  · 运放核心原理：差分输入，放大输出
  · 两条黄金法则：虚短（V+=V-），虚断（不取电流）
  · 同相放大：增益 = 1+R2/R1，不倒相
  · 反相放大：增益 = -R2/R1，倒相
  · 跟随器：增益=1，用于阻抗匹配
  · 比较器：输出高/低，用于阈值判断

【练习】
  1. 用LM358做一个同相放大器，增益为5倍，
     R1选10kΩ，R2应选多大？
  2. 电压跟随器的增益是多少？它有什么用？
  （参考答案：40kΩ；增益=1，用于阻抗匹配/信号缓冲）


================================================================
第6章  电源电路——给你的板子供电
================================================================

6.1  为什么电源电路很重要
--------------------------------

PCB设计中，电源电路是最基础的部分。
电源不稳，整个系统都不稳。
工控设备里很多奇怪的故障，根源都在电源。

本章讲两类电源电路：
  线性稳压器：简单可靠，效率低
  开关电源：复杂一些，效率高


6.2  线性稳压器——最简单的稳压电路
--------------------------------

原理：
  像一个"可调电阻"，
  自动调整自身压降，使输出电压恒定。

  输入 → [线性稳压器] → 输出（稳定）
  多余的能量以热量的形式消耗掉。

效率问题：
  输入5V，输出3.3V，效率 = 3.3/5 = 66%
  其余34%变成热量，所以输入输出压差大时要加散热片。

【最常用：7805系列（78xx）】

78xx 系列：正电压稳压器
  7805 = 输出+5V
  7812 = 输出+12V
  7833 = 输出+3.3V（有些型号有）
  最大输出电流：1A（TO-220封装）

79xx 系列：负电压稳压器
  7905 = 输出-5V（正负双电源时用）

典型接法（7805为例）：
  Vin（输入，需比5V高至少2V，通常7V-12V）
  GND（地，公共端）
  Vout（输出5V）

  必加电容：
  · 输入端：470μF电解电容 + 100nF陶瓷电容 并联到地
  · 输出端：100μF电解电容 + 100nF陶瓷电容 并联到地
  电容的作用：滤除纹波，防止振荡

【LDO稳压器（低压差）】

普通78xx需要输入比输出至少高2V（压差2V）。
LDO（Low Dropout）只需要高0.1-0.3V。

常用LDO：
  AMS1117：输出1.5V/1.8V/2.5V/3.3V/5V，最大1A
  XC6204：输出3.3V，最大150mA，体积小
  SPX3819：输出3.3V，低噪声，适合RF电路

LDO适合场合：
  · 锂电池（3.7V-4.2V）降到3.3V（只差0.4-0.9V）
  · 对噪声要求高的电路

使用注意：
  LDO输出端电容很关键，用错会振荡。
  看芯片数据手册确认推荐电容类型和容值。


6.3  开关电源——高效率的代价
--------------------------------

原理（降压Buck变换器为例）：
  高速开关（通常几百kHz）控制电感充放电，
  通过调节占空比（开关接通时间的比例）
  控制输出电压。

  占空比 = Vout / Vin
  例：输入12V，输出5V，占空比 ≈ 42%

效率：通常80%-95%（远高于线性稳压器）

缺点：
  · 电路复杂（需要电感、多个电容、控制芯片）
  · 产生开关噪声（EMI电磁干扰）
  · 设计不好会影响附近的模拟电路

【常见开关电源芯片】

降压（Buck）：
  MP2307：输入最大23V，输出可调，最大3A，很常见
  LM2596：输入最大40V，输出可调或固定，最大3A

升压（Boost）：
  MT3608：输入2V-24V，输出最高28V，最大2A
  XL6009：输入3-32V，输出5-35V，最大4A

【新手建议】
  初学先用线性稳压器（LDO/7805）。
  简单、稳定、容易调试。
  开关电源等熟悉PCB设计之后再用。
  很多模块（Arduino、树莓派）已经内置了开关电源，
  你可以直接用这些模块供电。


6.4  电源设计要点
--------------------------------

1. 去耦电容（每个芯片必须有）
   每个IC的VCC引脚旁，必须放：
   · 100nF（0.1μF）陶瓷电容（高频去耦）
   · 视情况加10μF电解电容（低频储能）
   电容要尽量靠近芯片引脚放置。
   这是PCB设计铁律，不加会出奇怪的故障。

2. 电源顺序（多电压系统）
   有些系统需要1.8V/3.3V/5V多种电压。
   某些芯片要求特定的上电顺序（核心电压先于IO电压）。
   查芯片手册的"Power Sequencing"章节。

3. 电源滤波
   电源进入PCB的地方，加LC滤波或大电容，
   防止外部干扰进入板内，也防止板内噪声出去。

4. 大电流走线
   电流越大，导线要越宽。
   0.1A：0.2mm宽度足够
   1A：至少1mm宽度
   5A：至少3-4mm宽度
   这在PCB布线时很重要。


【本章小结】
  · 线性稳压器：简单可靠，有压差损耗，初学优先
  · 78xx：固定电压，1A，老牌经典
  · LDO：低压差，适合电池供电
  · 开关电源：高效率，有噪声，熟悉后再用
  · 去耦电容：每个芯片必须有，放在引脚旁边
  · 大电流走线要宽

【练习】
  1. 用7805设计5V/500mA稳压电路，
     输入用9V，需要在输入输出各放哪些电容？
  2. 为什么去耦电容要放得离芯片引脚越近越好？
  （参考答案：输入470μF+100nF，输出100μF+100nF；
   离得近才能快速响应芯片的瞬时电流需求，
   远了走线电感会抵消作用）


================================================================
第7章  滤波器——让信号更纯净
================================================================

7.1  什么是滤波
--------------------------------

现实中的信号总是混着噪声。
传感器输出的模拟信号，经过长电缆后，
会混入各种干扰：工频50Hz干扰、高频噪声、
电机的开关噪声……

滤波器的作用：
  让有用的频率通过，阻止不需要的频率。

频率：信号每秒变化多少次，单位Hz。
  50Hz电源干扰：每秒变化50次
  音频信号：20Hz-20000Hz
  开关电源噪声：几百kHz以上


7.2  四种滤波器类型
--------------------------------

【低通滤波器（LPF）】
  低频通过，高频阻止。
  用途：滤除高频噪声，保留慢变化信号（如温度）
  
【高通滤波器（HPF）】
  高频通过，低频阻止。
  用途：去除直流偏置，提取快变化信号
  
【带通滤波器（BPF）】
  只允许特定频率范围通过。
  用途：收音机选台（只接收某个电台频率）
  
【带阻滤波器（陷波器）】
  阻止特定频率，其余通过。
  用途：去除50Hz工频干扰


7.3  最简单的RC低通滤波器
--------------------------------

电路：
  输入 → R → 输出
              |
              C
              |
             GND

这就是最简单的低通滤波器：一个电阻，一个电容。

截止频率（fc）：
  fc = 1 ÷ (2π × R × C)
  
  高于fc的频率：被衰减（信号变小）
  低于fc的频率：基本通过

例：R = 10kΩ，C = 100nF
  fc = 1 ÷ (2 × 3.14 × 10000 × 0.0000001)
  fc ≈ 159 Hz
  
  这个滤波器会通过0-159Hz的信号，
  衰减159Hz以上的频率。
  适合滤除温度传感器信号里的高频噪声。

例2：滤除工频干扰后让音频通过
  音频最低20Hz，工频50Hz——这个很难用简单RC区分。
  需要更复杂的滤波器，或者改善信号采集环境。


7.4  有源滤波器（运放+RC）
--------------------------------

简单RC滤波器的问题：
  会被后级电路的阻抗影响，性能不稳定。

解决方案：在RC后加运放缓冲，
或者用运放配合RC构成有源滤波器。

【萨伦-凯（Sallen-Key）二阶低通滤波器】

这是最常用的有源低通滤波器电路之一。
滚降速率（-40dB/decade）比简单RC（-20dB）更陡，
过渡更快，滤波效果更好。

电路结构稍复杂，建议参考在线计算器设计：
  搜索"Sallen-Key filter calculator"
  输入截止频率和所需增益，自动算出R、C值。

【实用建议】
  工控信号处理，先用简单RC低通滤波器就够了。
  截止频率设为信号最高频率的2-5倍。
  简单有效，成本极低。


7.5  实际应用举例
--------------------------------

【例1：ADC前端滤波】
  单片机ADC（模数转换）采样传感器时，
  在ADC输入引脚前加RC低通滤波器：
  R = 1kΩ，C = 10nF，fc = 16kHz
  可以滤除采样时的混叠噪声。

【例2：电源滤波】
  开关电源输出后，用LC滤波器去除开关纹波：
  L = 10μH，C = 100μF
  截止频率约5kHz，开关频率100kHz的噪声被大量衰减。

【例3：工频干扰抑制】
  传感器信号里有50Hz工频干扰：
  把信号改成差分传输（屏蔽双绞线），
  配合仪表放大器，共模干扰被抵消。
  比滤波器效果更好。


【本章小结】
  · 四种滤波器：低通、高通、带通、带阻
  · RC低通滤波：最简单实用，fc = 1/(2πRC)
  · 有源滤波器：运放提高性能
  · 实际首选：RC低通，简单够用
  · ADC前必须加低通滤波器

【练习】
  1. 设计一个RC低通滤波器，截止频率1kHz，
     选C = 100nF，R应选多大？
  2. 为什么说在ADC输入前必须加低通滤波器？
  （参考答案：约1.6kΩ，选标准值1.5kΩ或1.8kΩ；
   防止高频信号混叠，造成采样结果失真）


================================================================
第8章  传感器信号处理——实战应用
================================================================

8.1  传感器输出了什么
--------------------------------

传感器把物理量（温度、压力、位移、转速）
转换成电信号。常见输出类型：

  【电压型】：输出0-5V或0-3.3V对应量程
  · 举例：电位器（电压调节），霍尔传感器
  · 接法最简单，直接接ADC

  【电流型（4-20mA）】：输出4-20mA对应量程
  · 4mA对应量程最小值，20mA对应量程最大值
  · 工业现场最常用，抗干扰能力强（电缆长几百米没问题）
  · 接法：在传感器和地之间串联250Ω电阻，
    电流转换成1-5V电压，再接ADC

  【电阻型】：阻值随物理量变化
  · 举例：热敏电阻（NTC/PTC）、应变片
  · 接法：搭配分压电路，转换成电压

  【开关型】：输出高/低电平（有/无）
  · 举例：接近开关、光电开关、行程开关
  · 接法：上拉电阻接MCU输入引脚


8.2  热敏电阻（NTC）温度采集
--------------------------------

NTC热敏电阻：
  温度升高 → 阻值减小（负温度系数）
  温度25℃时阻值标称值，常见10kΩ

典型接法（分压采集）：
  +3.3V → 10kΩ固定电阻 → ADC输入 → NTC热敏电阻 → GND

计算温度：
  1. 读ADC值，换算成电压 Vadc
  2. 计算NTC阻值：R_ntc = R_fixed × Vadc / (VCC - Vadc)
  3. 用B值公式或查表换算成温度

注意：
  ADC引脚前加100nF去耦电容到地，
  再串一个100Ω-1kΩ小电阻（保护ADC引脚）。


8.3  4-20mA信号采集
--------------------------------

工业上大量使用4-20mA传感器（压力、液位、温度等）。

接收电路：
  传感器+ → 接电源正（或通过外部电源供传感器）
  传感器- → 249Ω精密电阻 → GND
  249Ω电阻两端 → ADC输入

  4mA × 249Ω = 0.996V ≈ 1V（对应量程0%）
  20mA × 249Ω = 4.98V ≈ 5V（对应量程100%）

如果ADC基准是3.3V，用124Ω电阻：
  4mA → 0.5V，20mA → 2.5V（在3.3V量程内）

精密电阻选0.1%精度，保证测量准确。

在ADC输入前，加RC低通滤波器（1kΩ + 10nF）。


8.4  信号放大——仪表放大器
--------------------------------

有些传感器输出信号很微弱，比如：
  热电偶：几十微伏/℃
  应变片电桥：几毫伏

这种微弱信号直接接ADC，噪声比信号还大，根本用不了。
需要放大几十到几百倍。

普通运放放大有问题：
  · 共模干扰一起被放大
  · 差分输入阻抗不对称

解决方案：仪表放大器（Instrumentation Amplifier, INA）

常用仪表放大器芯片：
  INA128：精密，低噪声，外接一个电阻设置增益
  INA226：带I2C接口的电流/电压监测（数字输出）
  AD620：低功耗，增益1-1000可调

INA128增益设置：
  增益 G = 1 + 50kΩ / Rg
  例：G = 100，则 Rg = 50k/(100-1) ≈ 505Ω，选510Ω

使用场景：
  · 热电偶温度测量（配合冷端补偿）
  · 应变片称重传感器
  · 电流检测（配合采样电阻）


8.5  光耦隔离——保护你的MCU
--------------------------------

工业现场有强电（220V/380V）和弱电（3.3V/5V）混用。
强电信号直接连接MCU会烧毁MCU。
光耦（光电耦合器）解决这个问题。

原理：
  输入侧：电信号驱动LED发光
  输出侧：光照射光敏三极管，产生电流
  输入和输出之间完全电气隔离（耐压通常1-5kV）

常用光耦芯片：
  PC817：最便宜、最常用，CTR≥80%，速度慢
  TLP521：和PC817类似
  6N137：高速光耦，用于高速信号（UART/SPI等）

典型应用：
  · 检测220V交流电的过零点
  · 接收工业PLC的24V信号，输入单片机
  · 驱动高压继电器
  · 隔离电机驱动信号，保护控制电路


【本章小结】
  · 传感器输出类型：电压型、4-20mA、电阻型、开关型
  · 4-20mA：工业首选，249Ω电阻转电压
  · NTC热敏电阻：分压电路采集，B值公式算温度
  · 仪表放大器：微弱差分信号放大，用INA128
  · 光耦：强弱电隔离，PC817最常用

【练习】
  1. 一个4-20mA传感器，量程0-100°C，
     当前电流12mA，对应什么温度？
  2. 为什么要用光耦而不是直接连接？
  （参考答案：(12-4)/(20-4)×100 = 50°C；
   防止强电损坏MCU，电气隔离保护设备）
